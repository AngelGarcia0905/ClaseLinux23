# Subtema 4.1: Arquitecturas Híbridas — Edge Computing vs. Cloud Computing

---

## 1. Cómputo en el Borde (Edge Computing)

* **Definición:** Procesamiento de datos en el mismo dispositivo donde se capturan las señales (ej. Raspberry Pi o nodo Debian conectado a sensores médicos).
* **Ventajas:** Latencia ultra-baja, privacidad de datos de salud y capacidad de operar sin conexión a internet.

---

## 2. Cómputo en la Nube (Cloud Computing)

* **Definición:** Delegación de tareas pesadas (entrenamiento de redes neuronales, inferencia de LLMs) mediante peticiones HTTP REST o WebSockets.
* **Arquitectura Híbrida:** Limpieza de datos en el borde (Edge) y consulta de modelos complejos en la nube (Cloud).
