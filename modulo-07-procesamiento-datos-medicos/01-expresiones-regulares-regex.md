# Subtema 7.1: Expresiones Regulares (Regex) en Datos Médicos

---

## 1. Sintaxis de Regex para Filtrado de Texto

* `^` / `$`: Anclajes de inicio y fin de línea.
* `[0-9]+` / `\d+`: Uno o más dígitos numéricos.
* `( ... )`: Grupos de captura para extraer variables específicas (ej. valores de Frecuencia Cardíaca BPM).
